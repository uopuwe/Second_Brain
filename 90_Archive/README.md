# 90 Archive

This folder is the terminal stage of the repository knowledge ingestion pipeline.

Canonical workflow:

- [Knowledge Ingestion Pipeline](../.codex/knowledge_ingestion_pipeline.md)

Use this folder for source packets that have completed processing from `00_Inbox/`.

Archive categories:

- `processed/`: reviewed source material with promoted or intentionally unpromoted content.
- `rejected/`: reviewed source material with no durable vault value.
- `superseded/`: source material replaced by a better or newer source.
- `sensitive/`: retained material that should not be promoted into general technical notes.

Do not use this folder as a dumping ground.
Every archived source should remain traceable to its source record, ingest report, or destination notes.
