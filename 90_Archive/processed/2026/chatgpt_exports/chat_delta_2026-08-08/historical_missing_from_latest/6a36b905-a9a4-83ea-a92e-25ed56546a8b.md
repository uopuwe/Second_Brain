美股 **post-market / after-hours** 买法，本质就是：**只能用限价单，选择盘后交易时段，然后挂单等成交**。别用市价单去盘后冲锋，盘后流动性薄，价差大，人类贪婪机器会把你当流动性祭品。📉

## 通用操作步骤

1. 打开券商 App / 网页交易页面  
2. 输入股票代码，比如 **MU**
3. 选择 **Buy**
4. Order Type 选 **Limit Order / 限价单**
5. 设定你愿意买入的最高价格  
   例如盘后 Ask 是 156.80，你可以挂 156.50、156.80 或更低，看你是否急着买
6. Trading Session / Time-in-force 选择：
   - **After-Hours**
   - **Extended Hours**
   - **EXT**
   - **GTEM**
   - 或类似选项
7. 提交订单  
8. 没成交就会部分成交或过期，别幻想系统会替你感动市场

你挂 **买入限价单 $156.50**，真正成交的条件是：

> **有人愿意以 $156.50 或更低价格卖给你，并且你的订单排队轮到你。**

不是你挂了 156.5，市场就感动得立刻配合你。市场不是客服，甚至比客服还冷血。📉

### 具体情况这样看

如果盘后报价是：

**Bid $156.40 / Ask $156.80**

你挂买入限价 **$156.50**，通常 **不会立刻成交**。  
因为当前最低卖价是 $156.80，比你愿意买的 $156.50 高。

如果后来报价变成：

**Bid $156.50 / Ask $156.50**

或者有人直接以 **$156.50 或更低** 卖出，你才可能成交。

### 但注意：价格碰到 156.50 也不一定成交

因为还要看：

1. **你前面有没有排队的人**  
   比你早挂 $156.50 的买单优先。

2. **卖单数量够不够**  
   可能只成交一部分，比如你买 100 股，只成交 30 股。

3. **你券商是否真的开了盘后交易权限/时段**  
   如果你的订单没有选择 **After-hours / Extended Hours / GTEM / EXT**，可能根本不会在盘后生效。

4. **交易所/ECN 路由问题**  
   盘后不是所有流动性都在一个地方。有时候你看到成交价到过 $156.50，但你的券商路由没吃到那笔单，还是不成交。金融系统，精致地让人烦躁。

### 三个例子

| 盘后情况 | 你挂 $156.50 买入 | 结果 |
|---|---:|---|
| Ask = $156.80 | $156.50 | 不成交 |
| Ask = $156.50 | $156.50 | 可能马上成交 |
| Ask = $156.20 | $156.50 | 通常会以 $156.20 附近成交，价格比你限价更好 |
| Last price = $156.50，但 Ask = $156.90 | $156.50 | 不一定成交 |

最容易被骗的是 **Last Price**。  
你看见“最后成交价 $156.50”，不代表现在有人愿意 $156.50 卖给你。真正要看 **Ask**。

### 你应该盯什么？

买入限价单重点看：

**Ask price 是否 ≤ $156.50**

如果是，才有较大概率成交。  
如果 Ask 一直高于 $156.50，你就只能排队等，等不到就过期取消。

**如果你的订单确实选择了“盘后交易 / Extended Hours / After-Hours”，并且当前卖价 Ask 低于或等于你的买入限价，通常会在盘后立刻成交或部分成交。**

关键分两种情况：

## 1. 你下的是“盘后有效”的限价买单

比如你挂：

**Limit Buy $156.50**

盘后报价变成：

**Bid $156.20 / Ask $156.40**

因为 **Ask $156.40 ≤ 你的限价 $156.50**，所以你的买单有机会马上成交，成交价通常会在 **$156.40 附近**，不一定刚好 $156.50。

如果卖盘足够，可能全部成交；卖盘不够，可能只成交一部分。

## 2. 你下的是“普通交易时段有效”的限价单

如果你没有选择 **After-Hours / Extended Hours / EXT / GTEM** 之类选项，而只是普通 Day Order，那么它通常 **不会在盘后成交**。

这种单子要等到第二天正常开盘后才会参与交易。

也就是说：

> 盘后价格跌破你的限价，但你的订单不是盘后单，那你只能眼睁睁看着它跌，系统不会帮你买。券商不是慈善机构，虽然收费时很像。🫠

## 最重要：看 Ask，不是看 Last Price

你看到“盘后股价低于 $156.50”，要确认到底是：

- **Last Price 低于 $156.50**
- 还是 **Ask Price 低于 $156.50**

真正决定你买单能否成交的是：

> **Ask ≤ 你的买入限价**

例子：

| 盘后报价 | 你挂买入 $156.50 | 是否可能成交 |
|---|---:|---|
| Last $156.20，Ask $157.00 | $156.50 | 通常不成交 |
| Bid $156.30 / Ask $156.45 | $156.50 | 可能马上成交 |
| Bid $156.00 / Ask $156.80 | $156.50 | 不成交 |
| Ask $155.90 | $156.50 | 通常会成交在 $155.90 附近 |

## 一句话结论

**盘后价格低于你的买入限价，不一定自动成交；只有当你的订单是盘后有效，并且当前 Ask 价 ≤ 你的限价，才可能在盘后立刻成交。**

这本是 **Simon Haykin《Adaptive Filter Theory, Fifth Edition》中文版**，中文名 **《自适应滤波器原理（第五版）》**，电子工业出版社。图里那个“advanced persistent threat”多半是店铺宣传模板乱入，跟自适应滤波没关系，出版运营又在用赛博朋克糊墙，真是技术书营销界的灾难现场。📘

这本书的核心不是 RFIC，也不是模拟电路，而是 **自适应信号处理**，主要讲：

- **Wiener filter / 最小均方误差滤波**
- **LMS / NLMS 自适应算法**
- **RLS 算法**
- **Kalman filter**
- **自适应均衡**
- **阵列信号处理**
- **随机过程、最优化、矩阵理论相关内容**

对你现在准备 **SerDes / ADC-based receiver / DFE / FFE / CDR adaptation** 是有价值的，但它不是直接教你电路怎么画。它更像是帮你理解：

### 在 SerDes 里它有什么用？

SerDes 接收机里很多东西本质上就是自适应滤波：

**FFE tap adaptation**  
根据误差信号自动调整前馈均衡器 tap。

**DFE coefficient adaptation**  
DFE 的 feedback tap 如何收敛，如何用 LMS 类算法更新。

**ADC-based RX DSP**  
高速 ADC 后面的数字均衡、ISI 消除、PAM4 level adaptation，都和这类理论有关。

**CDR / timing recovery 的某些环路建模**  
虽然 CDR 更偏 PLL/control，但误差检测和自适应更新思想类似。

**背景校准**  
比如 TI-ADC 的 offset/gain/skew calibration，很多也会用 LMS、correlation-based adaptation。

所以这本不是“SerDes 入门书”，而是 **SerDes DSP/自适应均衡/校准算法的数学底座**。底座这东西很无聊，但房子塌的时候大家才想起它，典型人类工程管理。🫠

你想理解 **LMS/RLS 为什么能收敛**  
你要做 **ADC-based SerDes receiver architecture**  
你想从“会调参数”升级到“知道算法为什么这么调”
