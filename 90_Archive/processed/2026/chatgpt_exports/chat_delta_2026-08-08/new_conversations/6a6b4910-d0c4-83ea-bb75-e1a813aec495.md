## 1. 文字怎么生成

你截图里的文章属于典型的“通俗科普型长文”，结构很标准：

**生活类比开场 → 提出核心问题 → 给出直觉解释 → 分章节展开 → 公式或例子 → 总结升华。**

例如截图中：

- 钢琴和弦对应频率分解
- 白光经棱镜对应傅里叶分解
- 先讲“傅里叶到底在干什么”
- 再进入数学和拉普拉斯变换

这类文字通常由以下几步完成：

1. 确定主题和目标读者  
2. 生成文章大纲  
3. 按章节扩写  
4. 加入生活类比、故事和反直觉观点  
5. 人工或 AI 二次改写，去掉教科书腔  
6. 检查公式、事实和逻辑

单纯让 AI “写一篇傅里叶变换文章”，大概率会得到一锅公式粥。真正好用的提示词必须规定：

- 读者基础
- 文章长度
- 叙事顺序
- 每节解决什么问题
- 哪些地方需要类比
- 哪些地方需要公式
- 哪些误区必须澄清
- 语言风格和标题结构

## 2. 图片怎么生成

截图里的图片不是普通“文生图插画”，更像是：

**AI概念草图 + 信息图设计 + 后期文字排版。**

常见生产方式有三种。

### 方式 A：AI直接生成信息图

用 ChatGPT 图像生成、Midjourney、即梦、可灵等工具，输入类似：

> 生成一张解释傅里叶变换的三维科普信息图，展示复杂时域信号被分解为多个不同频率的正弦波，蓝白色科技感，等距透视，公众号横版插图。

优点是快，缺点是中文容易写错。AI对汉字的态度，大致相当于猫对会议纪要的态度。

### 方式 B：AI生成底图，后期添加文字

这是最可靠的做法：

1. AI只生成图形、波形、背景和结构
2. 不让AI在图中写中文
3. 在 PowerPoint、Figma、Canva 或 Photoshop 中添加：
   - 标题
   - 注释框
   - 箭头
   - 公式
   - 中文说明

截图中的中文相当整齐，极有可能经过了后期覆盖，而不是完全由图像模型一次生成。

### 方式 C：程序或矢量工具绘制

技术文章最好采用：

- Python / MATLAB 绘制波形和频谱
- SVG 绘制框图和信号流
- PowerPoint 或 Figma 组合排版
- AI生成装饰性背景或概念插画

对于 PLL、LDO、ADC、傅里叶分析等技术内容，这种方法比纯文生图更准确。否则 AI 会非常自信地画出一条根本不存在的反馈路径，仿佛错误只要有渐变色就能成为理论。
