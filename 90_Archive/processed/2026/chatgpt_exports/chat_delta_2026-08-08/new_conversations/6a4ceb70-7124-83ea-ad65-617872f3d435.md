如果你的目标是为了**管理 Second_Brain、学习资料和代码**，那么只需要掌握 GitHub 的 20% 功能，就能完成 80% 的工作。很多人把 Git 和 GitHub 搞得神神秘秘，其实核心概念没有多少，只是软件工程师喜欢给简单的东西起很多名字，仿佛每多一个术语工资就能涨一点。🙃

## Git 和 GitHub 是什么？

很多新手第一步就混淆这两个。

- **Git**：版本管理工具，安装在你的电脑上。
- **GitHub**：云端服务器，用来保存 Git 仓库。

可以理解成：

```
Word      = 编辑文档
OneDrive  = 云端保存

Git       = 管理版本
GitHub    = 云端保存版本
```

也就是说：

> Git 可以没有 GitHub。
>
> GitHub 离不开 Git。

## GitHub 的作用

GitHub 相当于：

```
电脑
      ↓
Git
      ↓
GitHub 云端
```

即使电脑坏了：

```
新电脑

↓

git clone

↓

全部恢复
```

所以很多程序员电脑丢了都不慌。

真正慌的是忘记 `git push`，本地写了一周代码，结果硬盘先退休了。机器没有背叛你，它只是严格执行了物理定律。

# 第三步：把你的 Second_Brain 放进去

├── 02_Investing
├── 03_AI

├── Assets
└── README.md
```

打开 Git Bash：

```bash
cd C:\Users\你的用户名\Documents\Second_Brain

git init

git add .

git commit -m "Initial commit"
```

关联 GitHub：

```bash
git remote add origin https://github.com/你的用户名/Second_Brain.git
```

上传：

```bash
git push -u origin main
```

完成。

```

```

GitHub 上那些几千、几万 ⭐ 的项目，本质上就是别人公开分享的代码、工具或学习资料。你**不需要自己会写很多代码，也可以直接使用**。实际上，你以后学习 SerDes、PLL、Python、AI 工具时，会经常用到它们。

通常有四种使用方式，按难度从低到高。

---

## 第一种：直接下载（最简单）

很多项目根本不用 Git。

进入项目主页，例如：

```
https://github.com/用户名/项目名
```

点击右上角

```
Code
```

再点击

```
Download ZIP
```

下载后解压即可。

适用于：

- Python脚本
- 学习资料
- Markdown笔记
- PDF教程
- 示例工程

---

## 第二种：git clone（推荐）

如果已经安装了 Git：

```bash
git clone https://github.com/用户名/项目.git
```

例如：

```bash
git clone https://github.com/karpathy/nanoGPT.git
```

电脑上会出现

```
nanoGPT/
```

以后更新只需要：

```bash
git pull
```

而不用重新下载。

这是程序员最常用的方法。

---

## 第三种：按照 README 安装

几乎所有高 Star 项目都有一个

```
README.md
```

它就是说明书。

通常会写：

```
Installation

Usage

Examples

FAQ
```

例如：

```bash
pip install -r requirements.txt
```

意思：

安装作者需要的所有 Python 库。

然后：

```bash
python main.py
```

或者

```bash
python app.py
```

程序就运行了。

很多人一看到满屏英文 README 就放弃了，其实真正重要的往往就是安装和运行那几段命令，剩下不少内容是背景介绍、贡献指南之类。

---

## 第四种：Fork（准备自己修改）

如果你想：

- 增加功能
- 修改代码
- 长期维护

不要直接改原作者仓库。

而是：

点击

```
Fork
```

GitHub 会复制一份到你的账号。

以后：

```
原项目

↓

Fork

↓

你的仓库

↓

修改

↓

Push
```

完全不会影响作者。
