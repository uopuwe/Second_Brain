## Auto Skill 的工作原理

官方流程大致如下：

```
用户任务
      │
      ▼
扫描所有 Skill 的简介（不是全文）
      │
      ▼
判断哪个最相关
      │
      ▼
只加载那个 Skill
      │
      ▼
执行
```

它不会一开始把所有 Skill 都读进上下文，而是先读取每个 Skill 的元信息（名称、描述等），只有决定使用某个 Skill 时，才会加载对应的 `SKILL.md` 和相关资源。这样既节省上下文，又提高效率。citeturn0search3turn0search22

如果你说的是 **ChatGPT 的 Agent Skills（技能）**，它本质上就是把一套经常重复执行的工作，封装成一个可复用的"专业助手"。以后不用每次重新解释背景，AI 会按这套流程工作。人类终于把"复制粘贴工作说明"自动化了，也算是文明的小进步。😄 citeturn0search4turn0search9

### 一、什么时候适合做一个 Skill？

凡是满足下面两个条件，都适合：

* 经常重复
* 每次步骤基本一样

例如：

- 阅读论文并输出固定格式总结
- PLL Spec → Architecture → Noise Budget → Circuit Design
- 股票分析
- 每周工作总结
- 简历优化
- 邮件润色
- Word/PPT 自动排版
- PCB Review
- Verilog Review

---

### 二、如何创建 Skill

目前有两种方式。

#### 方法1：直接聊天创建（推荐）

直接告诉 ChatGPT：

> 帮我创建一个 Skill，用于分析224G SerDes PLL设计。

它一般会继续问：

- 这个 Skill 做什么？
- 输入是什么？
- 输出是什么？
- 有哪些固定流程？
- 有没有模板？

确认后即可安装。 citeturn0search9

---

#### 方法2：Skills 页面创建

进入：

> Skills
>
> → Create
>
> → Create with Chat

填写即可。 citeturn0search9turn0search4

---

### 三、以后怎么使用？

安装以后，不需要重新解释。

例如直接说：

> 用 PLL Review Skill 分析这份 Spec。

或者

> 用我的 SerDes Skill。

AI 会自动加载对应流程。
