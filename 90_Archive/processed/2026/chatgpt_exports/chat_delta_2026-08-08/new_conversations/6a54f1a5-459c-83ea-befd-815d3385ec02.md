下面给你一个**直接用于“生成新图片”**的 Markdown 指令模板。  
它不是“修改原图”的指令，而是：

> **按照我之前重绘后的那种统一风格，直接从内容生成全新的技术插图。**

你可以把它保存成：

`GENERATE_TECHNICAL_FIGURES_STYLE.md`

然后直接喂给 **Codex / Claude Code / 其他 agent / 图片生成工作流**。

---

```md
# Technical Figure Generation Spec
## For Razavi PLL / SerDes / Analog IC Notes
## Purpose: Generate new publication-style figures directly, not edit old images

---

## 1. 任务目标

为技术文档直接生成**全新高清图片**，风格统一为：

- 教材级
- IEEE / JSSC / ISSCC tutorial 风格
- 白底、简洁、可读性高
- 适合直接插入 Word / PDF
- 不依赖原始截图，不对原图进行“修复”或“放大”
- 输出的是**全新绘制的图**

这些图片主要用于：
- 模拟/射频/PLL/环振/VCO/LDO/相噪/调谐/多相时钟等技术笔记
- 对比图
- 流程图
- 电路概念图
- 波形示意图
- 相位/频率/相噪关系图
- 架构总结图
- 表格型信息图

---

## 2. 总体风格要求（必须遵守）

### 2.1 视觉风格
生成风格必须满足：

- 专业、技术化、干净
- 不是海报风，不是花哨信息图风
- 不是手绘风，不是卡通风
- 不是截图拼贴风
- 不是论文扫描风
- 不是低分辨率屏幕截图风
- 应当看起来像**重新绘制的矢量技术图**

### 2.2 背景
- 纯白背景
- 不要纹理
- 不要渐变背景
- 不要阴影背景
- 不要彩色底板铺满整页

### 2.3 分辨率与清晰度
- 高清
- 适合插入 Word 后仍清晰
- 所有文字必须在 100% 缩放下清楚可读
- 禁止小字堆叠
- 禁止极细线条
- 禁止把多个复杂子图挤在狭小区域

### 2.4 构图原则
- 信息分区清晰
- 尽量横向展开
- 留白合理
- 对齐整齐
- 图中各模块大小协调
- 若内容复杂，可拆成左右两栏或上下两区
- 重要结论必须视觉突出

---

## 3. 统一样式规范

### 3.1 字体风格
统一使用现代技术文档风格字体效果，类似：

- Arial
- Calibri
- Helvetica
- Source Sans 风格

要求：
- 标题加粗
- 小标题半粗
- 正文字体清晰
- 公式、符号、变量清楚
- 中英混排要自然
- 希腊字?
