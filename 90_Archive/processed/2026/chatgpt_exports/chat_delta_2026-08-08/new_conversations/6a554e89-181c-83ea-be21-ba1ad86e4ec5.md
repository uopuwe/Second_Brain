这张图已经把答案显示出来了：Moomoo 加拿大版在持仓表中同时提供了：

- **Average Cost：132.8496**
- **Total P/L：+$244.17**
- **Unrealized P/L：+$244.17**
- **Realized P/L：$0.00**

目前 XCHP 的 Total P/L 等于 Unrealized P/L，是因为系统记录的已实现盈亏为 0。因此：

\[
\text{有效成本}=\text{平均成本}=132.8496
\]

如果以后部分卖出产生盈利，例如实现盈利 $500，那么：

- Average Cost 仍可能显示 $132.8496
- Realized P/L 显示 +$500
- Total P/L = 已实现盈亏 + 未实现盈亏
- 但 Moomoo 加拿大版仍不会直接显示降低后的“有效成本”

按你这张图，XCHP 大约持有 78 股：

\[
10,606.44-244.17=10,362.27
\]

\[
10,362.27\div78\approx132.8496
\]

以后可以用表格里的数据直接算：

\[
\boxed{
\text{有效每股成本}
=
\text{Average Cost}
-
\frac{\text{Realized P/L}}{\text{当前股数}}
}
\]

例如已实现盈利 $500：

\[
132.8496-\frac{500}{78}
=
126.44
\]

也可以用：

\[
\boxed{
\text{有效成本}
=
\frac{\text{Market Value}-\text{Total P/L}}{\text{当前股数}}
}
\]

右上方“三条横线”只能调整显示字段；你现在已经把 **Total P/L、Unrealized P/L、Realized P/L** 全部调出来了，这就是加拿大版能提供的最完整显示。它把零件都给你了，就是死活不肯替你拧成“摊薄成本”，软件产品经理经典操作。

Moomoo 加拿大版目前不能把“有效成本/摊薄成本（Diluted Cost）”直接显示在持仓列表中。加拿大版固定显示 Average Cost，也就是你截图里的 QQC 成本 $40.1321；卖出盈亏不会摊进剩余股份成本。[Moomoo Canada 官方说明](https://www.moomoo.com/ca/support/topic10_78)

但可以查看包含历史卖出盈亏的累计结果：

**Accounts → Total Assets → P/L Analysis → P/L Ranking → All → QQC**

这里的 **Total P/L** 包括：

- 当前持仓浮盈亏
- 已卖出部分的实现盈亏
- 交易费用
- 现金分红及预扣税

[Moomoo Canada：P/L Analysis](https://www.moomoo.com/ca/support/topic10_181)

如果想换算成“有效每股成本”，用：

\[
\boxed{
\text{有效成本}
=
\frac{\text{当前市值}-\text{QQC Total P/L}}{788}
}
\]

例如QQC当前市值为：

\[
788\times49.23=38,793.24
\]

假设在 P/L Analysis 中看到 QQC 的 **Total P/L = $12,169.16**，那么：

\[
\text{有效成本}
=
\frac{38,793.24-12,169.16}{788}
=
\$33.79
\]

所以结论是：

- 持仓页的 $40.1321：税务/账面平均成本
- P/L Analysis：历史买卖后的累计真实盈亏
- $33.79：根据累计盈亏换算的有效成本，Moomoo 加拿大版不会直接显示

其他国家版本有“Diluted Cost”，加拿大版偏偏没有——同一个 App，功能也要搞地区歧视。

可以，但要单独建立一个“有效持仓成本”，不要修改券商的账面成本。券商显示的是当前持仓的平均成本，不会因为以前卖出赚钱或亏钱而改变。

从截图可以反推出：

- QQC 当前持有：788 股
- 券商平均成本：$40.1321
- 当前账面总成本：$31,624.09
- 当前未实现盈利：$7,169.16

## 计算公式

设：

- \(R\) = QQC 历史累计已实现净盈亏  
- 盈利为正数，亏损为负数

那么：

\[
\text{有效持仓总成本}
=
\text{当前账面总成本}
-
\text{历史已实现净盈亏}
\]

\[
\text{有效每股成本}
=
\frac{\text{当前账面总成本}-\text{历史已实现净盈亏}}
{\text{当前持股数量}}
\]

套入你的 QQC：

\[
\boxed{
\text{QQC有效每股成本}
=
\frac{31,624.09-R}{788}
}
\]

### 例1：以前卖出累计盈利 $5,000

\[
\text{有效每股成本}
=
\frac{31,624.09-5,000}{788}
=
\$33.79
\]

此时：

- 券商账面成本：$40.1321
- 自己统计的有效成本：$33.79
- 当前未实现盈利：$7,169.16
- 历史＋当前总盈利：

\[
7,169.16+5,000=\boxed{\$12,169.16}
\]

### 例2：以前卖出累计亏损 $2,000

亏损记为 \(R=-2,000\)：

\[
\text{有效每股成本}
=
\frac{31,624.09-(-2,000)}{788}
=
\$42.67
\]

历史亏损会抬高有效成本，这才真实反映这只股票到目前到底赚了多少，免得只盯着绿色数字自我感动。

## 更简单的现金流算法

如果能够导出全部 QQC 交易记录，直接计算：

\[
\text{净投入资金}
=
\text{全部买入金额及手续费}
-
\text{全部卖出净收入}
\]

\[
\text{现金流有效成本}
=
\frac{\text{净投入资金}}{\text{当前股数}}
\]

如果还想把分红也视为投资回收：

\[
\text{净投入资金}
=
\text{全部买入支出}
-
\text{全部卖出收入}
-
\text{累计现金分红}
\]

这个算法最干净，不需要逐笔先算已实现盈亏。

## 建议保留两个成本

| 指标 | 用途 |
|---|---|
| 券商账面成本／税务 ACB | 报税、计算下一次卖出的资本盈亏 |
| 有效持仓成本 | 衡量这只股票历史交易至今的真实盈亏 |

加拿大税务上，同一种证券采用平均成本法；出售一部分通常不会改变剩余股份的每股 ACB。CRA明确说明，处置相同证券不?
