# 第一步：GT/s 到 Gbaud

PCIe 5.0 以前采用 **NRZ(PAM2)**

每个 Symbol 有 **2 个电平**

每个 Symbol 只能表示

\[
\log_2(2)=1\text{ bit}
\]

因此

```
32 GT/s
=
32 Gbaud
```

因为

```
1 symbol = 1 bit
```

---

PCIe6/7 采用 PAM4

每个 Symbol 有

```
00
01
10
11
```

四种状态

所以

\[
\log_2(4)=2\text{ bits/symbol}
\]

因此

```
128 GT/s
```

实际上需要

```
64 Gsymbols/s
```

因为

```
64 Gbaud × 2 bits
=
128 Gb/s
```

所以

```
128 GT/s
=
64 Gbaud
```

# 第二步：为什么 Nyquist 是 Baud Rate 的一半？

Nyquist Frequency 定义为

> 一个数字波形能够表示的最高无混叠频率。

对于采样率

\[
f_s
\]

Nyquist 为

\[
f_N=\frac{f_s}{2}
\]

而这里

采样率实际上就是

```
Symbol Rate
```

因为每个 Symbol 更新一次。

因此

\[
f_N
=
\frac{64\text{ Gbaud}}2
=
32\text{ GHz}
\]

这就是 PCIe7 常说

```
Nyquist = 32 GHz
```
