严格说，并不存在“全球 PLL 专家联合签署的五条公约”。人类连 **loop bandwidth 到底按哪种定义报告**都能争论半天。但真正做过多次 tapeout、见过 silicon 抽自己耳光的人，基本都会采用下面五种核心思维模式。

## 1. **先定义测量，再设计电路**

PLL 设计不是从 VCO schematic 开始，而是从一句话开始：

> **这个指标究竟在什么条件下、哪个节点、通过什么滤波方法测量？**

例如“RMS jitter < 150 fs”至少还缺：

- 积分频率范围；
- 测量点是 VCO、PLL macro output 还是 lane endpoint；
- 是否包括 clock buffer、PI、package；
- spur 是否计入；
- SSC 是否开启；
- 是 raw jitter 还是经过 CDR/protocol transfer function 后的 jitter；
- 哪个 PVT、负载和工作模式。

缺少这些限定条件，150 fs 不是规格，只是穿着工程制服的愿望。

专家首先建立：

\[
\text{System Spec}
\rightarrow
\text{Measurement Definition}
\rightarrow
\text{Derived Block Spec}
\rightarrow
\text{Testbench}
\]

也就是 **Spec Compliance Matrix、clock plan 和 requirement traceability**。fileciteturn0file1

## 2. **把一切误差看成“噪声源 + 注入点 + 传递函数”**

专家不会笼统地问：

> “PLL 的 phase noise 为什么不好？”

而会问：

1. 哪个噪声源？
2. 从哪里注入？
3. 经什么 transfer function 到输出？
4. 在哪个 offset frequency 主导？
5. 最后如何转换成时间抖动？

典型规律是：

- reference、reference receiver、PFD、CP、divider 噪声，通常主要经过**低通型**闭环传递；
- VCO intrinsic phase noise，通常经过**高通型**传递；
- loop bandwidth 附近可能出现 peaking；
- output buffer、clock tree、PI 的噪声可能根本不经过 PLL 环路抑制。
