这通常**不是你的摩托罗拉手机坏了**，而是 **Android 对公共 Wi-Fi 的安全检查比 iPhone 更严格**。很多公共场馆（包括体育馆、机场、酒店）的登录 Wi-Fi（Captive Portal）都会出现这种情况。🤦 人类发明了免费 Wi-Fi，然后再发明几十种方式让你连不上。

如果提示的是：

- **"没有证书"**
- **"无法验证证书"**
- **"Certificate required"**
- **"安全证书有问题"**

一般有几种原因：

1. **NBO 的 Wi-Fi 登录页面证书配置有问题**
   很多公共 Wi-Fi 会把你重定向到登录页面，如果证书链配置不完整，Android（尤其 Motorola）可能直接拒绝。iPhone 往往还能继续。citeturn0search3turn0search6

2. **手机把它当成企业 Wi-Fi（802.1X）**
   如果连接界面出现：
   - EAP 方法
   - CA Certificate（CA证书）
   - Domain
   - Identity
   
   那说明手机认为这是企业网络。但 NBO 免费 Wi-Fi 一般不需要这些。

3. **Android 没有自动弹出登录页面**
   有时实际上已经连上 Wi-Fi，只是没有打开认证网页。citeturn0search3

### 你现在可以试试

按顺序来：

1. **忘记这个 Wi-Fi**
   设置 → Wi-Fi → 选中 NBO 网络 → 忘记。

2. **重新连接**

3. 如果连上但不能上网：
   打开 Chrome，访问一个 **http** 网站（不是 https）：
   ```
   http://neverssl.com
   ```
   或
   ```
   http://1.1.1.1
   ```
   这样通常会强制弹出登录页面。citeturn0search3turn0reddit16

4. 如果提示"证书"：
   - 不要安装任何未知证书。
   - 如果只是网页证书警告，可以查看是否有 **继续** 或 **高级** 选项；如果完全没有继续按钮，那就是场馆 Wi-Fi 配置问题，不是手机问题。citeturn0search0turn0search6
