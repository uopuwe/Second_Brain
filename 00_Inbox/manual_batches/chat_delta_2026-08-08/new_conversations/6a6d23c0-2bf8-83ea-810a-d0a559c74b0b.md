# Word 生成易错点清单（只列 AI 默认会弄错的）

> 生成中文技术文档（原生公式 + 重绘图 + 紧凑版式）时，把这几条明确交代给 AI。
> 通用常识（用 pandoc、公式要可编辑、图要清晰等）不重复。

## 公式
- LaTeX 里**禁用** `\tag`、`\boxed`、`\Bigl/\Bigr`（pandoc 转 OMML 会失败）。
  编号改写在公式内：`E=mc^2 \qquad (3.17)`；大定界符用 `\left[ \right]`。

## 中文字体（最常出错）
- 中文必须用 **Microsoft YaHei**，且在**三处同时**设置，缺一即回退成 Cambria 标注中文：
  1. `theme1.xml` 的东亚槽位 `<a:ea typeface=""/>`（常为空）→ 填 `Microsoft YaHei`
  2. `styles.xml` 里所有 `w:eastAsiaTheme="…"` → 改为显式 `w:eastAsia="Microsoft YaHei"`
  3. `document.xml` 里 run 级的 `eastAsiaTheme` 引用同样替换
- **粗体**样式必须含 `<w:bCs/>` 并指定东亚字体，否则中文粗体几乎看不出来。

## 版式（pandoc 默认值需手动覆盖）
- 正文 10 磅：改 `<w:sz w:val="20" />`。注意 pandoc 写法**带空格**，默认值是 24（=12磅）不是 22。
- Narrow 边距：pandoc 生成的是**空标签** `<w:sectPr />`，没有边距可改；
  必须整体替换为注入了 pgMar 的完整 sectPr（四边 720 缇 = 1.27 cm）。
- 标题段前距默认过大，压到 160/120 缇。

## 插图（默认会选错工具）
- 示意框图/坐标图用**手写 SVG → rsvg-convert 转 PNG**，不要用 matplotlib
  （它的下标缺字形、文字溢框、箭头错位）。
- SVG 里下标用 tspan 手工做（`font-size:70%` + `dy` 升降 + 零宽字符复位），
  不要用 Uni?

# Word 生成易错点清单（只列 AI 默认会弄错的）

> 生成中文技术文档（原生公式 + 重绘图 + 紧凑版式）时，把这几条明确交代给 AI。
> 通用常识（用 pandoc、公式要可编辑、图要清晰等）不重复。

## 公式
- LaTeX 里**禁用** `\tag`、`\boxed`、`\Bigl/\Bigr`（pandoc 转 OMML 会失败）。
  编号改写在公式内：`E=mc^2 \qquad (3.17)`；大定界符用 `\left[ \right]`。

## 中文字体（最常出错）
- 中文必须用 **Microsoft YaHei**，且在**三处同时**设置，缺一即回退成 Cambria 标注中文：
  1. `theme1.xml` 的东亚槽位 `<a:ea typeface=""/>`（常为空）→ 填 `Microsoft YaHei`
  2. `styles.xml` 里所有 `w:eastAsiaTheme="…"` → 改为显式 `w:eastAsia="Microsoft YaHei"`
  3. `document.xml` 里 run 级的 `eastAsiaTheme` 引用同样替换
- **粗体**样式必须含 `<w:bCs/>` 并指定东亚字体，否则中文粗体几乎看不出来。

## 版式（pandoc 默认值需手动覆盖）
- 正文 10 磅：改 `<w:sz w:val="20" />`。注意 pandoc 写法**带空格**，默认值是 24（=12磅）不是 22。
- Narrow 边距：pandoc 生成的是**空标签** `<w:sectPr />`，没有边距可改；
  必须整体替换为注入了 pgMar 的完整 sectPr（四边 720 缇 = 1.27 cm）。
- 标题段前距默认过大，压到 160/120 缇。

## 插图（默认会选错工具）
- 示意框图/坐标图用**手写 SVG → rsvg-convert 转 PNG**，不要用 matplotlib
  （它的下标缺字形、文字溢框、箭头错位）。
- SVG 里下标用 tspan 手工做（`font-size:70%` + `dy` 升降 + 零宽字符复位），
  不要用 Unicode 下标字符 ₁₂（CJK 字体常缺字形）。
