## 怎么购买

直接点击图片中的 **Add credits**：

1. 进入充值页面，选择积分金额或充值档位。
2. 确认付款货币、税费和信用卡。
3. 选择一次性购买即可。
4. 不建议首次就打开 **Auto top-up**。自动充值开启后，余额低于设定值会自动扣卡补充，悄无声息得像订阅服务最擅长的那种关怀。
5. 购买后可在 **Codex → Settings → Usage → Credits / Usage Dashboard** 查看余额和每次任务的消耗。citeturn212943view0turn688891view0

购买积分不会改变你的 Plus 套餐，也不会提高当前显示的 9%。它只是让你在套餐额度耗尽后继续工作。citeturn212943view0
