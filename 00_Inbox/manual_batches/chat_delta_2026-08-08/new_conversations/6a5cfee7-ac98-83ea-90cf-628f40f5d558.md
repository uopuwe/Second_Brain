# 一、市级公开文件没有明确写“死亡前连续两年”

北京市住房城乡建设委现行公开文件的原文是：

> 原承租人迁出本市或者死亡，与原承租人同一户籍并共同居住两年以上且无其他住房的家庭成员，可以申请继续承租。

这份市级文件没有明确写：

- 必须在原承租人死亡当天仍在该户籍；
- 必须是死亡前连续两年；
- 曾经满足两年以上、后来因婚迁出的，一律不能申请。

因此，单从市级文件字面看，杜凤绵可以提出以下解释：

1. 她是原承租人的女儿，属于家庭成员；
2. 她确实曾与原承租人同一户籍；
3. 她确实共同居住超过两年；
4. 她现在属于无房户；
5. 其他符合条件的家庭成员没有异议。

也就是说，市级条文字面上写的是“共同居住两年以上”，并没有直接写成“原承租人死亡前两年持续同户居住”。citeturn705863search1

# 二、为什么实际办理时仍可能被拒绝

问题在于，“与原承租人同一户籍并共同居住两年以上”通常不是被理解为童年时期曾经住过就永久取得资格。

否则几乎所有已经成家、迁出几十年的子女，都可以凭小时候与父母同住而申请承租，公房承租资格就会变成某种祖传收藏品。这显然不是政策设计目的。

房管部门通常会考察申请人在原承租人死亡或者迁出时，是否仍然属于该公房的实际共同居住家庭成员，包括：

- 原承租人死亡时是否仍在本址户籍；
- 死亡前是否连续实际居住；
- 是否已经另行成家并长期在别处生活；
- 户口迁出后是否形成新的独立家庭；
- 是否承担房租、水电、维修或者照料义务；
- 该房是否仍是申请人的主要、唯一住房。

北京市司法局公布的行政复议案例说明，房管部门认定是否“共同居住”，必须根据实际证据判断，不能仅凭几份笼统证明就否定申请人。该案最终撤销了事实证据不足的拒绝答复，但案例中的申请人是否已经将户口迁出，并不是其核心争议。citeturn705863search0

所以这个案例能支持你们要求房管部门认真调查，却不能直接证明“迁出户口后仍必然符合”。

- 原承租人死亡或者迁出本市；
- 申请人与原承租人 **同一户籍**；
- 与原承租人 **共同居住两年以上**；
- 申请人 **无其他住房**；
- 其他符合承租条件的家庭成员无异议；
