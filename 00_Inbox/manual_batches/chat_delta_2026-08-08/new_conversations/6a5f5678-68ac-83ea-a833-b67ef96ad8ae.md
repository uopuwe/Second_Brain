这是 Hi-Fi 系统里的三个功能，它们经常可以做成一台机器，也可以拆成三台机器。**你的 Naim Uniti Star 就是一台“三合一”设备。**

可以把整个系统理解成这样：

```
音乐文件
    │
    ▼
Streamer（播放器）
    │
    ▼
DAC（数字转模拟）
    │
    ▼
前级（音量控制、信号选择）
    │
    ▼
后级（功率放大）
    │
    ▼
B&W 804 D4
```

下面分别解释。

### 1. Streamer（数字播放器）

作用就是**把音乐读出来**。

例如：

- Tidal
- Qobuz
- Spotify
- NAS
- USB
- 网络电台

它相当于以前的 CD 转盘。

你的 **Uniti Star** 已经包含：

- 网络串流
- CD 播放
- USB 播放
- AirPlay
- Chromecast

所以它本身就是一个很优秀的 Streamer。

---

### 2. DAC（Digital to Analog Converter，数模转换器）

音乐在电脑里其实是一串数字：

```
010101001010101...
```

音箱根本听不懂数字。

DAC 的作用就是：

```
数字
↓

连续模拟电压

↓

声音
```

DAC 的好坏会影响：

- 细节
- 背景宁静度
- 人声质感
- 空间感

你的 Uniti Star 里面已经有 DAC。

---

### 3. 前级（Preamplifier）

很多人误以为前级只是控制音量，其实远不止如此。

它负责：

- 音量控制
- 输入切换
- 输出到后级
- 信号缓冲
- 阻抗匹配

输出的是：

**小电压、小电流的音乐信号。**

它没有能力推动音箱。

你的 Uniti Star 就包含前级。

---

### 4. 后级（Power Amplifier）

后级负责：

**把很小的音乐信号放大几十倍甚至几百倍。**

例如：

前级输出：

```
1V
```

后级输出：

```
30V
几十安培瞬时电流
```

这样才能推动 804 D4。

所以后级决定：

- 动态
- 控制力
- 低频
- 瞬态
- 声压

---
