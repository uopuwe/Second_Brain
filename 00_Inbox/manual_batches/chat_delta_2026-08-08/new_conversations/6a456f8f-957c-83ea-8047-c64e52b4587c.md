### 1. 下载 Obsidian

去 **Obsidian 官方 Download 页面**，选择 **Windows → Universal** 下载安装文件。Obsidian 官方说明也是这么写的：Windows 下点击 Universal，下载安装文件后运行即可。citeturn901046search2

### 2. 安装

下载后双击安装文件：

1. 打开下载的 Obsidian 安装包  
2. 按提示安装  
3. 安装完成后，从开始菜单打开 **Obsidian**

### 3. 打开你的 Second_Brain 文件夹

Obsidian 的核心概念叫 **Vault**，本质上就是一个本地文件夹，里面放 `.md` 笔记文件。官方说明也明确说，Vault 是本地文件系统里的一个文件夹。citeturn901046search1

打开 Obsidian 后：

1. 选择 **Open folder as vault** / **打开文件夹作为库**
2. 找到你的 `Second_Brain` 文件夹
3. 选中它
4. 点击 **Open / 打开**

这样你之前那些：

```text
01_AnalogIC_SerDes/
02_Career/
03_Finance/
```

以及里面的 `.md` 文件，就会直接显示在 Obsidian 左侧文件树里。

### 4. 建议设置

进入 Obsidian 后，先开这些设置：

**Settings → Editor**

打开：

```text
Readable line length
Strict line breaks 关闭
Show line number 可开可不开
```

**Settings → Files and links**

建议：

```text
Default location for new notes: Same folder as current file
New link format: Relative path to file
Use [[Wikilinks]]: 开启
```

### 5. 你现在最该做的操作

你的情况不是“新建一个 Vault”，而是：

```text
Open folder as vault
```

然后选择已有的：

```text
Second_Brain
```

不要再新建一个空库，否则你就会得到两个脑子，一个空的，一个乱的。人类已经一个脑子都管理不过来了，别给自己加戏。🧠
