# 二、真正的突破不是NPU，而是超大统一内存

普通高端PC通常是：

```text
CPU
├── 系统内存：32GB或64GB
└── 独立GPU显存：16GB、24GB或32GB
```

大模型必须尽量装进GPU显存。即使电脑有128GB系统内存，GPU显存只有24GB，一个40GB的模型也可能装不进去，或者必须频繁在系统内存与GPU之间搬运数据，速度惨得很有教育意义。

AMD的新结构是：

```text
CPU ─┐
GPU ─┼── 共享128GB统一内存
NPU ─┘
```

CPU和集成GPU使用同一个大内存池，不再严格区分“系统内存”和“显存”。ROCm文档也说明，Ryzen APU通过GPU虚拟内存管理共享系统内存，而不是依赖独立显存池。citeturn241549search2turn241549search9

这使它能够装下远超普通显卡显存容量的大模型。

## 核心判断

**100年前，电力革命把“肌肉和机械动力”变成了可以随处调用的基础设施；今天，AI正在把一部分“认知能力”变成可以随时调用、近乎无限复制的基础设施。**

真正被改变的，不只是某些职业，而是过去几千年以人脑为核心形成的社会生产模式：

> 人学习知识 → 人执行任务 → 人协调其他人 → 人检查结果 → 人承担责任。

未来更可能变成：

> 人定义目标和约束 → AI执行大量认知任务 → 人或另一套AI检查 → 人承担最终责任。

因此，AI不会简单地“取代人脑”，而会让**大量原本必须由人脑逐项完成的工作，不再值得由人亲自完成**。这比“某些岗位消失”深刻得多。

# 一、电力革命真正替代的，并不是蒸汽机

很多人把历史讲成：

> 蒸汽机下岗，电动机上岗，生产率暴涨。

这属于教科书为了照顾人类有限耐心而进行的粗暴压缩。

早期工厂通常由一台中央蒸汽机通过长轴、皮带和齿轮，把动力传给整座工厂。机器必须围绕动力轴排列，厂房布局僵硬，停一处可能牵连整条生产线。

最初引入电力时，很多工厂只是用一个大型电动机替换蒸汽机，继续保留原来的轴和皮带。因此生产方式几乎没变，生产率提升也有限。

真正的革命是后来出现的**单机电驱动**：

- 每台机器拥有独立电动机；
- 机器可以按生产流程而不是动力轴位置排列；
- 可以单独启停、调整速度；
- 工厂可以重新设计成流水线；
- 生产管理、建筑结构、物流和劳动分工一起变化。

历史研究发现，电气化从19世纪末开始扩散，但美国制造业显著的生产率加速主要发生在20世纪20年代。因为必须等旧设备折旧、建设新厂房、培养管理人员并重新组织生产。技术已经出现，人类组织却拖着脚走了几十年，这个传统保持得相当稳定。citeturn999894search0turn755584search0turn755584search4

所以，电力革命的公式不是：

\[
生产率提升 = 电动机效率
\]

而是：

\[
生产率提升
=
电力技术
\times
工厂重构
\times
新设备
\times
管理制度
\times
劳动力技能
\]

AI也是如此。

### 2. Claude Code

**Claude Code不是模型，而是安装在电脑上的编程代理程序。**

你安装的：

```text
Claude Code v2.1.207
```

是Anthropic开发的终端程序。它负责把模型接入你的本地项目，并提供实际操作能力，例如：

- 显示聊天和任务界面；
- 管理当前会话；
- 知道当前工作目录；

- 修改本地文件；
