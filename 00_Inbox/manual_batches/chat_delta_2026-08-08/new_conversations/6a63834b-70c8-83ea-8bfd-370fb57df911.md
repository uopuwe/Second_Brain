# 一、杜瑛卓方案最大的法律不确定性

## “无房”看申请时，还是看李志清死亡时？

这是整条路线的命门。

北京市2017年通知表述为：原承租人死亡后，与其同一户籍并共同居住两年以上且无其他住房的家庭成员，可以申请变更承租人。通知没有明确写明，“无房”必须在原承租人死亡时就满足，还是在申请审批时满足。citeturn328880view0

但《北京市公有住宅租赁合同》的公开文本使用过“与乙方外迁或死亡时同一户籍共同居住两年以上又无其他住房”的表述。语法上，房管部门可能把“死亡时”理解为资格状态的判断时间，而不只是户籍判断时间。citeturn359940search9

因此存在两种完全不同的审批口径：

| 审批口径 | 杜瑛卓卖房后的结果 |

| 以申请或审批时的房产状态为准 | 真实卖房后可以成为无房户 |
| 以李志清死亡时的状态为准 | 后来卖房也不能补正原来的有房状态 |
| 综合考虑死亡时和申请时 | 由房管局根据目的、时间及真实性判断 |
