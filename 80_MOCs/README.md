# 80 MOCs

This folder contains Maps of Content.

Canonical architecture:

- [Knowledge Architecture](../.codex/knowledge_architecture.md)

MOCs answer:

- How do concepts connect?
- What should be read first?
- Which notes form the core of a topic?
- Which permanent notes, reference notes, indexes, and handbooks belong together?

MOCs are not raw file listings.
Use `70_Indexes/` for inventory pages.
